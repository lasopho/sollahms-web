## Evaluación por plataforma

| Plataforma | Qué revisar | Evidencia de resultados |
|---|---|---|
| Google Search y funciones generativas | Descubrimiento, canonicals, indexación, snippet, identidad y control efectivo de inclusión en Search Console; presentación cuando haya una observación real | GSC por las URL incluidas, inspección y rastreo posterior a T0; informe generativo si existe para la propiedad; muestras de Google con país/idioma/dispositivo/consulta exacta |
| OpenAI / ChatGPT Search | Accesibilidad de contenido útil y verificable; OAI-SearchBot separado de GPTBot; conservar preferencias de entrenamiento | Respuestas reales en contexto limpio con búsqueda, fuentes originales y clasificación independiente de mención, enlace, cita y recomendación; una API o búsqueda general no sustituye ese producto |
| Bing / Microsoft Copilot | Acceso de Bingbot, descubrimiento e indexación en su propio motor; identidad, fuentes y preferencias vigentes de uso | Bing Webmaster Tools y AI Performance cuando estén accesibles; evidencia directa de Copilot separada de Bing y de ChatGPT; las citas no equivalen a posición o tráfico |

Un requisito documentado para Google, como un formato de favicon, no demuestra una necesidad ni un beneficio equivalente en ChatGPT o Copilot. Compartir HTML/metadatos consistentes puede ser una base técnica común; el efecto por plataforma permanece no medido hasta obtener evidencia pertinente. No añadir archivos IA, schema, permisos, herramientas o servicios nuevos solo para aparentar cobertura de las tres plataformas.

## Contrato para cada respuesta, cambio o publicación

Relacionar el trabajo con el estudio mediante: objetivo y página incluida, hallazgo concreto, criterio del estudio, aplicabilidad Google/OpenAI/Bing, resultado esperado como hipótesis, evidencia/verificación posible y limitaciones. Una plataforma puede quedar "sin efecto específico acreditado" o "no medida"; no inventar una mejora para completar la tabla.

Separar siempre **implementado, publicado, rastreado/indexado, observado en búsquedas, citado/recomendado por IA y resultado comercial atribuido**. Registrar fuente, fechas, zona nativa, filtros y versión de alcance. Una comparación usa el mismo conjunto de páginas y periodos completos equivalentes; `null` no es cero. Las consultas de marca se conservan separadas, con `Sollams` a secas como prioritaria y `Sollahms` como nombre oficial.

Antes de publicar, comprobar producción y conciliar novedades; aprobar y validar un candidato concreto según el encargo, preservando funciones, configuración, SSO, dominios e integraciones. La instrucción de alineación permanente no aprueba por sí sola un deployment ni una fusión. Reutilizar el circuito prebuilt certificado del proyecto cuando corresponda, con Production sin dominios y promoción del mismo ID validado.
