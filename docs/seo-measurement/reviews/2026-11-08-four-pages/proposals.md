# Propuestas exactas para revisión — cuatro páginas

Nueve cambios editoriales propuestos; ninguno aplicado. Las propuestas no autorizan publicación. Se mantienen destinos de contacto, formularios, consentimiento, variables, cálculos y funcionamiento. Los títulos, descripciones y encabezados no citados como cambio se conservan según el informe.

## H01 — https://sollahms.cl/ — Meta description

**Actual:**

> Asesoría para invertir en propiedades en Chile. Compara ubicaciones y proyectos con Sollahms para aumentar tu patrimonio y diversificar tus inversiones.

**Problema observado:** La descripción solo expresa inversión, mientras Expertise también ofrece comparación para vivir. Explica menos el servicio que el objetivo patrimonial.

**Propuesta exacta:**

> Asesoría inmobiliaria en Chile para comprar o invertir. Compara ubicaciones y alternativas, revisa tus objetivos y solicita orientación con Sollahms.

**Justificación:** Reutiliza el servicio explícito ya publicado: comparar características, ubicación y condiciones según el objetivo de vivir o invertir.

**Fuente:** [evidence/home.txt](evidence/home.txt), captura publicada del 8/11/2026.
