## Bing — recuperación desde el sitio existente

**Responsable:** propietario o usuario ya autorizado. **Estado de acceso Codex:** no hay conector BWT ni interfaz controlable; no se ha abierto la cuenta. El CNAME previo acredita un registro de verificación, no el estado actual de propiedad o informes. Los pasos se contrastaron con documentación oficial el 10/11/2026; algunos rótulos pueden variar por idioma/versión.

1. Abrir [Bing Webmaster Tools](https://www.bing.com/webmasters/), iniciar sesión con el mismo proveedor/cuenta usado antes y abrir el selector de sitios. Seleccionar el sitio existente que cubra `https://sollahms.cl/`. Guardar `bing/00-propiedad.png` recortado a URL/estado/permisos, sin identidad ni correo de cuenta; anotar la URL literal seleccionada. Si no aparece, probar únicamente las otras cuentas propias ya utilizadas o consultar al administrador anterior; guardar el resultado como `site_not_found_in_checked_accounts`, no crear/importar sitio ni renovar DNS.
2. Abrir **Search Performance / Rendimiento de búsqueda** → selector de fechas → rango máximo disponible. Bing documenta **16 meses**; la cuenta puede tener menos historial. Registrar inicio/fin reales y última fecha con datos. La ayuda antigua aún habla de seis meses: no reducir artificialmente a seis ni garantizar 16 para esta cuenta. Seleccionar la fuente **Web** si se ofrece; si el rótulo es **Web and Chat** o **All**, conservarlo literal y no renombrarlo «Web orgánico». Pulsar **Download / Descargar** para el CSV de la gráfica; después abrir **Pages / Páginas** y **Keywords / Palabras clave**, descargando cada tabla cuando el control esté disponible. Nombres de entrega: `bing/01-performance-fechas-general.csv`, `02-performance-paginas-general.csv`, `03-performance-consultas-general.csv`. Guardar `01-filtros.png` con sitio, periodo, fuente y filtros. Si no existe descarga de una tabla, guardar captura y declarar `export_not_offered`, sin fabricar CSV nativo. Estos archivos son **general no filtrada** hasta aplicar la lista positiva.
3. En **Pages**, abrir únicamente cada URL de las 11 incluidas y exportar sus **associated keywords / consultas asociadas** si la interfaz lo permite: `bing/page-01-consultas.csv` … `page-11-consultas.csv`, con captura de URL/filtros. Si hay serie diaria filtrada a esa página, exportar `page-NN-fechas.csv`. No suponer que admite una expresión regular como GSC. Registrar por archivo si es total de página, tabla parcial de consultas o serie diaria; no sumar tablas marginales/consultas para simular totales. La documentación advierte que tablas y gráfica pueden diferir y que Pages/Keywords no cubren todas las superficies. Una URL sin fila exportada no implica cero. [Rendimiento](https://www.bing.com/webmasters/help/search-performance-c680da36) y [ampliación de historial](https://blogs.bing.com/webmaster/2024/10/Bing-Webmaster-Tools-Extends-Search-Performance-Data-to-16-Months/).
4. **Sitemaps** → abrir la fila del sitemap ya conocido, sin añadir/reenviar. Guardar `bing/04-sitemaps.png` y un CSV si se ofrece, con URL, estado, fechas y cifras visibles. Si el panel permite detalle de cobertura, conservar el resultado existente; cualquier total de dominio permanece **general no filtrada**. **Site Explorer** → usar búsqueda/filtro de URL exacta cuando esté disponible para las 11 URL; guardar estado/motivo visible. Si no permite ese recorte, usar solamente URL Inspection; no recorrer fichas. [Mapa de funciones](https://www2.bing.com/webmasters/help/refreshed-webmaster-tools-7c7d2533).
5. **URL Inspection / Inspección de URL** → pegar una URL incluida → leer la pestaña del **índice**, no **Live URL**. Repetir solo para las 11 URL del registro. Guardar `bing/inspection-01.png` … `inspection-11.png` y completar la tabla común con URL exacta, estado, razón literal, descubrimiento/rastreo/indexación y canonical si se muestra; desconocido queda vacío/null. Inspeccionar no equivale a **Request indexing**: no pulsar esa acción, Live URL ni iniciar Site Scan. [Inspección oficial](https://www.bing.com/webmasters/help/URL-Inspection-55a30305).
6. **IndexNow** → leer panel existente: periodo, URLs Submitted, Sources, última actividad y estado visible. **View complete report** permite consultar el historial; **Download all** exporta la tabla cuando se ofrece. Guardar `bing/05-indexnow-estado.png` y `05-indexnow-export.csv`; conservar resultados generales separados y filtrar posteriormente solo las 11 URL, sin abrir fichas. Registrar «sin actividad visible en ese periodo» si corresponde, no «integración inexistente». No pulsar configurar, generar clave, enviar o submit. La ayuda indica UTC como valor por defecto de los tiempos de envío IndexNow sin zona explícita; esta regla no se aplica a Search Performance. [IndexNow: panel, exportación y zona](https://www.bing.com/webmasters/help/indexnow-0z209wby).
7. Si aparece **AI Performance**, abrir **Citations & Pages**, seleccionar el mayor periodo realmente ofrecido y guardar `bing/06-ai-performance.png` más export nativo si existe; registrar URL citada, fecha, citas y grounding queries disponibles. En **Topics / Topics Portfolio**, elegir hasta tres meses si se ofrece y guardar `07-topics-portfolio.png` más export disponible. Si no hay export, entregar tabla manual claramente etiquetada y capturas, no llamarla export nativo. La pestaña Topics requiere suficientes datos y sus medidas son direccionales/aproximadas; ausencia de pestaña no significa cero citas. Estas métricas no ejecutan ni sustituyen las pruebas de los cinco productos IA. [Topics Portfolio](https://blogs.bing.com/webmaster/2026/10/introducing-topics-portfolio-beta-in-ai-performance/).

**Recepción mínima:** propiedad literal + captura sanitizada del selector; CSV originales disponibles y sus filtros/periodo; once inspecciones; estado de sitemap, IndexNow y disponibilidad AI/Topics. En el manifiesto registrar fuente=Bing, instante de extracción ISO8601 con zona, periodo, zona nativa mostrada (`unknown` si no se informa), fuente/vertical literal, alcance, límites de filas, formato y si hubo datos incompletos. No convertir etiquetas diarias a Santiago ni usar 09/11 como día completo antes/después. Entregar solo material permitido sin nombres/RUT/correos/teléfonos de personas, cookies o credenciales; no cargar originales privados a Git.
