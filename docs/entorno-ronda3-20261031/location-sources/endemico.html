Proyecto

Categoría y concepto único.

Proyecto de conservación de especies endémicas del lugar con invernadero, protección y fortalecimiento. Primera línea borde playa, sistema solar fotovoltaico conectado a Net Metering para iluminación de espacios comunes, piscina con sistema solar para aumento de temperatura.

UBICACIÓN INIGUALABLE

Condominio privado, con acceso directo a la playa y a 2km de Punta de Lobos.
