## Protección y reproducción

Los nuevos 36 medios Ingevec (22 imágenes y 14 planos) están ignorados por Git y sólo se entregan a la Preview autenticada mediante subida de archivos de despliegue. El repositorio público conserva sus manifestaciones de procedencia y HTML con bloques de revisión, pero no esos nuevos archivos. Para reproducir la revisión completa se usa `scripts/materialize-ingevec-brochures.py` con los originales privados, se verifica el manifiesto y se despliega exclusivamente a Preview. Un checkout de Git sin medios privados compila con los fallbacks anteriores.

Los assets AJ ya formaban parte del historial de la base antes de esta tarea; este trabajo conserva sus bytes y la restricción de build. No se reescribe ese historial. La autorización de difusión pública de ambos lotes sigue pendiente.

La autenticación SSO existente de Vercel se conserva. No se crea un enlace de bypass ni se cambian dominios, protección, variables de Production o configuración bancaria. La revisión automática rechazó crear una clave persistente de descifrado; no se envió ninguna clave ni se creó la variable. La solución final no requiere secretos nuevos.

No se modifica `main`, otras ramas ni Production; no se contratan servicios. El commit de entrega está únicamente en la rama autorizada. Los registros privados de comprobación y candidatos se conservan fuera de Git para continuidad.
