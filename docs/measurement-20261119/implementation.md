## Microsoft Clarity

Campos: `replay.projectId`, `replay.enabled`, `replay.strictMaskingVerified`, `replay.allowedPaths`. Debe acreditarse el modo Strict del proyecto. Antes del SDK, el módulo añade `data-clarity-mask="True"` a la raíz HTML y retira cualquier unmask existente; nunca añade zonas unmasked. Sólo se encola `consentv2` con `analytics_Storage:granted`, `ad_Storage:denied` tras el permiso independiente de replay. No se usa identify, tags de usuario, texto, datos financieros ni IDs de CRM.

Cobertura de replay: seis rutas (`/`, agenda, contacto, privacidad, colaboración e inversión empresarial). Se bloquean cinco páginas con herramientas financieras/orientadores: comparador, guía, cuándo comprar, Centro y beneficios tributarios. Sus SVG/atributos/estilos pueden depender del escenario; una máscara de texto no demuestra que esos valores queden suprimidos. También se excluye Entorno, cuyos filtros usan history.replaceState para modificar la URL durante la sesión. GA4 con eventos limitados conserva alcance de 12 rutas.

También se bloquea replay si existe query, hash desconocido, referrer con query/hash, ruta externa (p. ej. conversación de ChatGPT) o contexto de página excluida. Los anclajes públicos literales del HTML se admiten sin recarga (`#expertise`, `#solicitar-asesoria`, etc.); no se acepta cualquier ID dinámico. Ante un hash desconocido mientras hay replay se solicita recarga conservando la URL, y el nuevo documento bloquea el SDK; el ensayo local no acredita que Clarity real no pueda observar ese cambio antes de completarse la navegación. El sitio actual no usa pushState de datos personales ni escenarios en URL. Estos guards no constituyen un sistema general de saneamiento de URL para futuras aplicaciones SPA.

Las máscaras se aplican a grabaciones futuras y no acreditan anonimización absoluta: Clarity trata datos de navegación/dispositivo y URL/referrer además de DOM. Retención documentada: grabación normal 30 días; una selección de sesiones, favoritas/etiquetadas y datos agregados/heatmaps pueden conservarse hasta 9 meses. No etiquetar ni marcar favoritas que prolonguen retención sin una finalidad autorizada. No afirmar que todos los datos se borran en 30 días. Clarity no sustituye Bing Webmaster Tools ni mide por sí mismo citas de Copilot.
